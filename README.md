# emoji-quiz

絵文字を使った英語のクイズを行うWebアプリ。
絵文字データは、「emoji-v18.csv」を利用する。

## 仕様

- ブラウザからアクセスすると、「Emoji Quiz!」というタイトルと「Start」ボタンが表示されている。
- 「Start」ボタンを押すと、クイズ画面に遷移する。

### クイズ画面

- 画面上部に絵文字のnameが表示されている。
- 画面下部に4つのボタンがあり、それぞれの絵文字が絵で表示されている。
- どれか1つのボタンだけが、nameと一致する絵文字である。
- 正解なら、スコアが1増える。
- 不正解ならスコアは増えない。
- 正解でも不正解でも相応しい効果音が鳴る。
- 10問終わると終了。
- 画面左上の「✕」ボタンで、ゲームを中断してタイトルに戻れる。誤タップに備え、押すと確認ダイアログ（「Keep playing」「Quit」）が表示される。

## 技術仕様

- HTML/CSS/TypeScriptを使用
- 静的Webサイトで起動する

## 確認事項（Q&A）

実装にあたって確認した内容と、その回答。

| # | 確認したこと | 回答 |
|---|---|---|
| 1 | 出題する絵文字の範囲 | 「emoji-v18.csv」の全件。現在 1,581 件（確認済み）。なお、絞り込み前の全 1,923 件は「emoji-v18-master.csv」に残してある |
| 2 | 効果音の用意の仕方 | Web Audio API で合成する（音声ファイルは使わない） |
| 3 | TypeScript のビルド方法 | Vite |
| 4 | 不正解の選択肢の選び方 | ランダム（出題範囲から、正解以外を無作為に 3 つ） |

### 仕様で決められていなかったため、仮に決めた点

仕様に書かれていないので、以下のとおり実装した。違っていたら教えてほしい。

- 10問の間に、同じ絵文字は正解として2回出題しない。
- 回答すると正解／不正解をボタンの色で示し、約1秒後に次の問題へ進む。
- 10問終わったら、スコア（10点満点）と「Play again」ボタンを表示する。
- 画面上部に「何問目か」と現在のスコアを表示する。
- ブラウザの制約により、効果音は「Start」ボタンを押した後から鳴る。

## 開発方法

```sh
npm install
npm run dev        # 開発サーバー
npm run build      # dist/ に静的ファイルを出力
npm run preview    # ビルド結果の確認
```

## 備考

注意点

- index.html のダブルクリックでは動きません。 ブラウザの制約で、file:// では JS モジュールが読み込まれません。必ず HTTP サーバー経由で開いてください。
- デプロイするのは dist/ の中身です。 ソースやプロジェクトのルートではなく、dist/ の中身をホスティング先にアップロードします。
