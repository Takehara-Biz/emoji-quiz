# emoji-quiz

絵文字を使った英語のクイズを行うWebアプリ。
絵文字データは、「emoji-v18.csv」を利用する。

## 仕様

- ブラウザからアクセスすると、「Emoji Quiz!」というタイトル、英語の説明文（「Pick the emoji that matches the English word. You have 10 seconds! How many can you get right?」）、「Start」ボタンが表示されている。
- 「Start」ボタンを押すと、クイズ画面に遷移する。

### クイズ画面

- 画面上部に絵文字のnameが表示されている。
- 画面下部に4つのボタンがあり、それぞれの絵文字が絵で表示されている。
- どれか1つのボタンだけが、nameと一致する絵文字である。
- 正解なら、連続正解数（スコア）が1増える。
- 不正解ならゲーム終了。間違えるまで続く（問題数の上限はなく、無限に続く）。
- 回答時間は10秒。画面に「9.59」のように秒単位（小数第2位まで）で表示され、時間とともに減っていく。
- 正解すると、残りの回答時間が1秒増える。
- 回答時間が0秒になってもゲーム終了。
- 正解でも不正解でも相応しい効果音が鳴る。
- ゲーム終了時は、何問連続で正解したかと、解いた問題の絵文字と名前の一覧（正解は ✓、間違えた・時間切れの問題は ✗。長い場合は一覧内で縦スクロール）を表示し、「Back to start」（スタート画面に戻る）と「Play again」（もう一度やる）のボタンを表示する。
- 画面左上の「✕」ボタンで、ゲームを中断してタイトルに戻れる。誤タップに備え、押すと確認ダイアログ（「Keep playing」「Quit」）が表示される。

## 技術仕様

- React + TypeScript + CSSを使用（Next.jsは使わない）
- 静的Webサイトで起動する

## 確認事項（Q&A）

実装にあたって確認した内容と、その回答。

| # | 確認したこと | 回答 |
|---|---|---|
| 1 | 出題する絵文字の範囲 | 「emoji-v18.csv」の全件。現在 1,581 件（確認済み）。なお、絞り込み前の全 1,923 件は「emoji-v18-master.csv」に残してある |
| 2 | 効果音の用意の仕方 | Web Audio API で合成する（音声ファイルは使わない） |
| 3 | TypeScript のビルド方法 | Vite（@vitejs/plugin-react） |
| 4 | 不正解の選択肢の選び方 | ランダム（出題範囲から、正解以外を無作為に 3 つ） |

### 仕様で決められていなかったため、仮に決めた点

仕様に書かれていないので、以下のとおり実装した。違っていたら教えてほしい。

- 同じ絵文字は、全件を一巡するまで正解として2回出題しない（一巡したら並べ直して続ける）。
- 回答すると正解／不正解をボタンの色で示し、約1秒後に次の問題へ進む。
- 回答後の正解／不正解の演出中と、中断の確認ダイアログの表示中は、回答時間を止める。
- 画面上部に「何問目か」と現在の連続正解数を表示する。
- ブラウザの制約により、効果音は「Start」ボタンを押した後から鳴る。

## 開発方法

```sh
npm install
npm run dev        # 開発サーバー
npm run build      # dist/ に静的ファイルを出力
npm run preview    # ビルド結果の確認
```

## 備考

注意点

- index.html のダブルクリックでは動きません。 ブラウザの制約で、file:// では JS モジュールが読み込まれません。必ず HTTP サーバー経由で開いてください。
- デプロイするのは dist/ の中身です。 ソースやプロジェクトのルートではなく、dist/ の中身をホスティング先にアップロードします。
